
Re-ingest your PDFs into Chroma using POST /ingest?force=true or via the 
UI "Sync Knowledge" button to index the documents with the new continuous 
semantic chunks

Docker command
docker compose -f docker/docker-compose.yml up --build 

If using docker - Restart your Docker container to reload the code changes:
docker compose -f docker/docker-compose.yml down
docker compose -f docker/docker-compose.yml up --build
or
docker compose -f docker/docker-compose.yml restart
